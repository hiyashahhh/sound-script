# SoundScript 🎬

**Where storytelling meets sound.**

SoundScript is an AI-powered film music composition assistant that bridges cinematic storytelling, music intelligence and generative AI to support story-driven musical creation.

## Features

- AI-assisted film music composition
- Retrieval-Augmented Generation (RAG)
- Context-aware music recommendations
- Cinematic storytelling and music knowledge retrieval

## Tech Stack

- Python
- React
- TypeScript
- Vite
- LangGraph
- Retrieval-Augmented Generation (RAG)

## Project Structure

- `backend/` – Python backend and RAG pipeline
- `frontend/` – React frontend
- `backend/knowledge/` – Music knowledge base

## Getting Started

### Backend

1. Navigate to the backend directory.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Configure your environment variables using your own API credentials.
5. Start the backend using the project's configured startup command.

### Frontend

1. Navigate to the frontend directory.
2. Install dependencies:

   `npm install`
